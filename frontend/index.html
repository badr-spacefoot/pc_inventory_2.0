Collecte transparente

Ce collecteur recupere uniquement les informations d'inventaire utiles a l'equipe IT.

  • hostname, OS, fabricant, modèle et numéro de série
  • CPU, RAM, stockage, GPU si disponible
  • IP locale, MAC si autorisee, utilisateur OS connecte

Aucun fichier personnel, historique navigateur, mot de passe ou outil de controle distant n'est lu ou installe.
