# Parcéo Collector 0.1.54 — Sillage

Nouvelle identité Parcéo Sillage : logos, icônes Windows/macOS/Linux, thèmes clair/sombre et polices locales Manrope/IBM Plex Mono. L’identité Windows et les raccourcis utilisent désormais Piqa.Parceo.Collector. Cette version inclut les corrections de sécurité et de fiabilité du collecteur préparées lors de l’audit.

**Distribution manuelle non signée, autorisée par le propriétaire du projet.** L’installateur Windows ne porte pas de signature d’éditeur reconnue. L’application macOS n’est pas notariée (signature ad hoc de fonctionnement uniquement). SmartScreen et Gatekeeper peuvent donc afficher un avertissement. Aucun certificat de test n’est fourni ou installé et aucune protection système n’est désactivée.

Les vérifications de signatures des mises à jour automatiques restent en place. Cette release ne contient pas de manifeste de mise à jour signé et n’est pas diffusée automatiquement. Le canal signé stable et ses anciennes URLs restent disponibles.

Installez manuellement le paquet correspondant à votre plateforme. Les noms techniques et le protocole spacefoot-collector sont conservés pour les installations existantes. Vérifiez les fichiers avec SHA256SUMS.txt. Le paquet source inspectable est également fourni.
