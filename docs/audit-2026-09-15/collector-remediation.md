## Signing provisioning and publication

1. Obtain a Windows trusted code-signing certificate usable by the existing PFX pipeline (or adapt pipeline to a supported signing service). Configure `WINDOWS_CODESIGN_PFX_BASE64`, `WINDOWS_CODESIGN_PASSWORD`, and `WINDOWS_PUBLISHER_THUMBPRINT` (repository variable). A self-signed certificate is not a production substitute.
2. Obtain Apple Developer ID signing/notarization access. Configure `MACOS_CERTIFICATE_BASE64`, `MACOS_CERTIFICATE_PASSWORD`, `MACOS_CODESIGN_IDENTITY`, `MACOS_NOTARY_APPLE_ID`, `MACOS_NOTARY_TEAM_ID`, `MACOS_NOTARY_PASSWORD`.
3. Generate/manage an Ed25519 release key offline under administrator control. Store raw 32-byte private-key base64 as `COLLECTOR_UPDATE_PRIVATE_KEY` secret and raw 32-byte public-key base64 as `COLLECTOR_UPDATE_PUBLIC_KEY` variable. Do not publish or place private keys in source. Build validates and embeds only the public key without access to the private key. Only the production-environment release job receives the private key and checks the pair before signing. Configure environment protection rules in GitHub; YAML naming alone is not an approval policy.
4. A tagged release emits `collector-releases.signed.json` alongside verified artifacts. Publishing the release automatically serves this envelope at the compiled GitHub URL (`https://github.com/badr-spacefoot/pc_inventory_2.0/releases/latest/download/collector-releases.signed.json`), with HTTPS validation on every redirect. Keep the existing plain frontend/legacy-client manifest separate and unchanged. No extra Pages copy is required; before a signed release exists the missing endpoint safely disables updating. The signed manifest expires after 30 days; a maintained signed refresh process is required if no new release is issued. Expiry stops updates, not collection.
5. Before replacing the default API with the VPS canonical endpoint, verify new links, old drafts and Windows/macOS/Linux update relaunch. Do not retire hosted Supabase based only on a successful web deployment. Rotate publisher/key only with a planned old-client trust transition.
