Préparer l’intégration

Copier les dossiers d’assets sous /assets/brand/parceo/ en conservant les chemins. Les balises prêtes à copier se trouvent dans web/head-snippet.html. La CSS parceo-tokens.css fournit les variables et les polices locales ; la classe d’exemple .parceo-theme s’active explicitement.

Le manifeste décrit l’identité web ; il ne crée pas un fonctionnement hors ligne. Dans une interface native, garder la police système tant que le chargement privé des TTF n’est pas validé.

Garder une marque cohérente

  • Utiliser les SVG fournis ; conserver les proportions et l’accent de Parcéo.
  • Employer la version claire sur fond sombre et réserver la zone libre.
  • Ne pas étirer, tourner, recolorer, ombrer ou recomposer le signe.
  • En dessous de 320 px de large, remplacer le logo complet Collector par le symbole et un titre d’interface lisible.
Les maquettes sont illustratives. Cette livraison contient les assets et les règles de marque ; l’application, les builds distribués et le DNS restent inchangés.

Contrôles locaux : vecteurs, dimensions et conteneurs, contrastes, glyphes et chargement des maquettes. Les nouveaux fichiers n’ont pas fait l’objet d’une recette native sur macOS ou d’une épreuve d’impression. Disponibilité de marque à vérifier avant une diffusion publique.
